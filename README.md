🎓 NextGen Academy – AI Student Support Assistant
📌 Project Overview
NextGen Academy is a placement and skill development platform designed to help students become industry-ready through practical training, interview preparation, and career guidance.
This project includes an AI-powered Student Support Assistant that answers student queries, provides course information, and assists with enrollment-related questions 24/7.
